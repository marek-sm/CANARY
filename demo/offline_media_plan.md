# W9-T5 offline media and accessibility plan

> **Pre-results preparation only.** The organizer-confirmed slot and hardware
> are not yet recorded. This plan assigns no duration, makes no live-first
> promise, and contains no empirical result.

## Source of every recorded statement

| Segment | Source | Recording rule |
|---|---|---|
| Opening and evidence boundary | [`transcript_scaffold.md`](transcript_scaffold.md) | Say that the trace is fictional, illustrative, excluded, and not statistical evidence |
| Trusted task and untrusted observation | Schema-valid replay record rendered by `make replay` | Read only the generated task, policy, channel, and trust-boundary text |
| Event sequence | Stored `events.jsonl` and `results.jsonl`, rendered by `demo.trace` | Preserve requested, authorized, blocked, dispatched, execution, effect, sink, disclosure, utility, and unknown states separately |
| Accessible result structure | `make report` with no records | Show empty generated shells only; do not type a result or placeholder number over them |
| Fallback | The staged read-only replay | Announce the switch; do not describe a replay as live evidence |

## Capture preparation

- Use a clean terminal theme with large text and a contrast-checked foreground
  and background.
- Capture the full label and value together; never make color or position the
  only way to identify a state.
- Keep credentials, provider consoles, local usernames, host paths, raw
  restricted payloads, and unsanitized run records out of frame.
- Record the generated replay from a no-key, no-network checkout. Do not record
  a paid or live model call for this asset.
- Preserve the original recording and an edited copy so caption timing can be
  corrected without changing the evidence source.

## Verification before release

- [ ] Replay and report run from a fresh clone with no key and no network.
- [ ] Spoken words match the edited transcript.
- [ ] Captions identify speakers and meaningful non-speech audio and are timed
      after the final edit.
- [ ] Every visible chart has matching alt text and a table equivalent generated
      from the same frozen sanitized bundle.
- [ ] Unknown evidence is spoken and displayed as unknown, never as false.
- [ ] The recording contains no credential, personal data, host path, provider-
      only metadata, restricted payload, or unsupported claim.
- [ ] The project lead approves every result, number, and limitation before the
