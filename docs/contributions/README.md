# Contribution Records

This directory records verifiable public contributions without becoming a performance-management system. Records support accurate credit in the README, report, video, and release metadata.

Create one file per contributor identifier. Use a person's public name only after that person confirms the spelling, role description, and consent to publication.

## Record template

```markdown
# Contributor: [public name or contributor ID]

- Public-name consent: Yes | No | Pending
- Preferred public name: [only when consented]
- Component or research role: [specific scope]
- Active interval: [dates or release range]

## Verifiable contributions

- Pull request/commit/artifact: [link or identifier]
  - Work performed: [specific action]
  - Acceptance evidence: [test, review, source audit, generated output]
  - Independent reviewer: [consented name or contributor ID]

## Approved public description

[One factual sentence limited to this contributor's work.]

## Final review

- Contributor reviewed this record: Yes | No
- Review date: YYYY-MM-DD
```

Do not record selection rationale, ranking, private feedback, missed-work commentary, sensitive contact details, or speculative claims. A contribution statement describes completed, evidenced work; it does not grade the person.
